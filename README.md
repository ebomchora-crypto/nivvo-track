# NivvoTrack
Rastreador de vendas e painel de decisão para tráfego pago (Next.js + Supabase).

Fase 1 pronta: schema/RLS, evento normalizado, adaptadores Kiwify/Hotmart (provisórios), tracker.js.

```bash
npm install && npm test
```
Variáveis: ver `.env.example`. Aplique `supabase/migrations/0001_schema.sql`. Plataformas: `docs/plataformas.md`.
